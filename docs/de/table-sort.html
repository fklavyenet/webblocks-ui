Tabellensortierung

Barrierefreie Sortierung nach einer Spalte für vollständige lokale Daten und serverseitig paginierte Ergebnisse.

Behalten Sie die Standard-Tabellenstruktur bei. Verwenden Sie den Client-Modus nur bei vollständig geladenen Daten und den Server-Modus für entfernte oder paginierte Listen. Actions und Auswahlspalten bleiben unsortierbar.

Client-Sortierung ausprobieren

Navigieren Sie mit Tab zur Überschrift und drücken Sie Enter oder die Leertaste. Neue Spalten beginnen aufsteigend; erneutes Aktivieren sortiert absteigend. Leere Werte bleiben in beiden Richtungen am Ende.

Die Kopfzeilen verwenden die mitgelieferten Masken wb-icon-arrow-up-down, wb-icon-arrow-up und wb-icon-arrow-down in 16px direkt neben dem Text. Binden Sie webblocks-icons.css zusammen mit webblocks-ui.css ein; eine Icon-Bibliothek oder Runtime ist nicht erforderlich.

Dieses statische Beispiel unterbindet die Navigation und zeigt die angeforderte URL. Zeilen und Sortierstatus bleiben unverändert. Eine echte Anwendung sortiert den gesamten gefilterten Datensatz vor der Paginierung und stellt den Ergebnisstatus dar.

Aktivieren Sie eine Server-Überschrift, um ihre URL anzuzeigen.

Server-Links enthalten die URL für die nächste Sortierung und funktionieren ohne JavaScript. Server-Buttons verwenden die aktuelle URL oder data-wb-sort-url. Filter und Hash bleiben erhalten; die Seite wird auf 1 zurückgesetzt. Validieren Sie Sortierschlüssel und Richtungen im Backend über eine Positivliste.

      <a class="wb-table-sort" href="/admin/users?role=editor&amp;sort=name&amp;direction=desc&amp;page=1">Name</a>
    </th>
  </tr></thead>

AJAX-Integration

Unterbinden Sie wb:table-sort:request, um Daten selbst abzurufen. Aktualisieren Sie aria-sort erst nach Darstellung einer erfolgreichen Antwort mit WBTableSort.update. Zeigen Sie Fehler im Kontext und brechen Sie veraltete Anfragen ab oder ignorieren Sie sie. Das folgende Beispiel benötigt einen Anwendungs-Endpunkt und eigene DOM-Hilfsfunktionen.

const table = document.querySelector('#users');
const error = document.querySelector('#users-error'); // An inline wb-alert, initially hidden.
const pagination = document.querySelector('#users-pagination'); // Inside wb-card-footer.
let pending;
table.addEventListener('wb:table-sort:request', async (event) => {
  if (event.target !== table || event.detail.mode !== 'server') return;
  event.preventDefault();
  if (pending) pending.abort();
  const request = new AbortController();
  pending = request;
  table.setAttribute('aria-busy', 'true');
  error.hidden = true;
  try {
    const response = await fetch(event.detail.url, {
      signal: request.signal, headers: { 'Accept': 'application/json' }
    });
    if (!response.ok) throw new Error('Request failed');
    const result = await response.json();
    if (pending !== request) return;
    // Host-defined helpers build DOM from validated data using textContent.
    // The endpoint returns rows, pagination, sort and direction after allowlisting.
    const body = renderRows(result.rows);
    const footer = renderPagination(result.pagination);
    table.tBodies[0].replaceWith(body);
    pagination.replaceChildren(footer);
    WBTableSort.update(table, result.sort, result.direction);
    history.replaceState(null, '', event.detail.url);
  } catch (cause) {
    if (pending === request && cause.name !== 'AbortError') error.hidden = false;
  } finally {
    if (pending === request) {
      table.removeAttribute('aria-busy');
      pending = null;
    }
  }
});

WBTableSort.init(fragment) kann wiederholt werden. Verwenden Sie destroy vor dem Ersetzen von Überschriften oder Entfernen einer Tabelle. Der Client-Modus unterstützt eine Kopfzeile, ein tbody und keine verbundenen Zellen. Native Buttons unterstützen Tastaturaktivierung; Server-Links verwenden Enter. Form und aria-sort vermitteln die Richtung; abgeschlossene Sortierungen werden über eine Live-Region angekündigt.
