Erste Schritte

Binde die gebauten Assets ein, setze die Theme-Attribute am Root-Element und beginne bei den Patterns, statt aus einzelnen Primitives zu raten.

1. Paketdateien einbinden

Das kleinste korrekte Setup bindet die Haupt-Bundles für CSS und JS ein. Ergänze das Icon-CSS nur, wenn du klassenbasierte Icons mit <i class="wb-icon wb-icon-*"> nutzen willst. Doku und Playground in diesem Repository laden dieselben gebauten Dateien aus dem lokal veröffentlichten dist-Pfad, damit die Beispiele mit der ausgelieferten Paketausgabe übereinstimmen.

<link rel="stylesheet" href="/packages/webblocks/dist/webblocks-ui.css">
<link rel="stylesheet" href="/packages/webblocks/dist/webblocks-icons.css">
<script src="/packages/webblocks/dist/webblocks-ui.js" defer></script>

Keine zusätzliche Schicht nötig

Du brauchst weder Framework-Wrapper noch ein eigenes Starter-Stylesheet oder eine separate Komponenten-Runtime, um das Paket korrekt zu nutzen.

Icon-Weg über mask-image Dieser Guide nutzt den ausgelieferten klassenbasierten Icon-Weg mit webblocks-icons.css und <i class="wb-icon wb-icon-...">. Binde dieses Stylesheet ein, wenn du dasselbe Icon-Verhalten willst.

2. Theme-Attribute am Root setzen

Die Theme-Achsen liegen auf dem <html>-Element. Das Theme-Modul des Pakets liest und aktualisiert diese Attribute für dich.

<html data-mode="auto"
      data-accent="royal"
      data-preset="corporate"
      data-radius="soft"
      data-density="compact">
Mode

light, dark oder auto

Accent und Preset

Accent ändert das Farbsystem. Preset wendet ein benanntes Bündel von Achsenwerten an.

3. Von einem Pattern ausgehen

Der schnellste korrekte Weg besteht nicht darin, zuerst jedes Primitive durchzusehen. Beginne bei der Aufgabe der Seite und sieh dir dann die Surfaces und Primitives an, die das Pattern verwendet.

Dashboard Shell Admin- und datenlastige Screens
Nutze dies, wenn die Seite Sidebar-Navigation, eine Topbar und strukturierten Hauptinhalt braucht.
Content Shell Doku, Onboarding, längere Texte
Nutze dies, wenn Fließtext, Hierarchie und Lesebreite wichtiger sind als dichtes Anwendungs-Chrome.

4. Das nächstliegende ausgelieferte Beispiel kopieren

Die Pattern-Beispielseiten in diesem Guide sind nützlich, weil sie Shell-Wahl, Hierarchie, Surfaces, Primitives und Verhaltens-Hooks bereits an einer Stelle vereinen - ohne die Doku-Navigation zu verlassen.

Admin-Dashboard Topbar, Sidebar, Stats, Tabellen
Gute erste Vorlage, wenn die Seite eine Anwendungsoberfläche mit Navigation und dichtem operativem Inhalt ist.
Admin-Einstellungen Einstellungsabschnitte und destruktive Abläufe
Gute erste Vorlage, wenn die Seite ein langsamerer Einstellungs-Workflow mit gruppierten Feldern und ergänzenden Beschreibungen ist.
Auth-Login Schmale Einstiegs-Screens mit einer Aufgabe
Gute erste Vorlage, wenn die Seite visuelle Ruhe braucht und auf eine einzige Formularaufgabe zentriert bleiben soll.
Öffentliche Startseite Hero, Promo, ruhigerer Seitenrhythmus
Gute erste Vorlage, wenn die Seite marketinggetrieben, redaktionell oder öffentlich ist statt anwendungslastig.
Playground HTML testen, bevor du integrierst
Nutze dies, wenn du bereits Markup hast, KI-generierte Snippets ausprobieren willst oder echte WebBlocks-Assets in der Vorschau sehen musst, ohne zuerst eine ganze Seite aufzusetzen.

5. Zuständigkeiten klar halten

CSS und JS behalten ihre eigenen Aufgaben Layout wird von CSS bestimmt. Overlays, Tooltips, Tabs, Drawers, Theme-Umschaltung und das Verhalten der Command Palette laufen über ausgelieferte JavaScript-Hooks. Ergänze kein JS, um Layout nachzubilden, und kein CSS, um fehlendes Verhalten nachzubilden. 
<button class="wb-btn wb-btn-primary">Speichern</button>
<div class="wb-card">...</div>
<table class="wb-table wb-table-hover">...</table>
<button data-wb-mode-set="dark">Dunkel</button>
<button data-wb-accent-set="forest">Forest</button>
<button data-wb-preset-set="minimal">Minimal</button>
<button data-wb-toggle="modal" data-wb-target="#demoModal">Dialog öffnen</button>
<button data-wb-toggle="modal" data-wb-target="#mediaViewer">Viewer-Modal öffnen</button>
<button data-wb-toggle="drawer" data-wb-target="#demoDrawer">Filter</button>
<button data-wb-toggle="cmd" data-wb-target="#siteCmd">Suchen</button>
