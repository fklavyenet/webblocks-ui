Breadcrumb

wb-breadcrumb zeigt die aktuelle Position innerhalb einer Hierarchie aus Seiten oder Abschnitten. Es ist ein semantisches Pattern ganz ohne JavaScript - für Admin-Header, Doku-Flächen, CMS-Abläufe und zurückhaltenden Kontext auf öffentlichen Seiten.

PatternOhne JavaScriptCSS-Trennzeichen
Überblick Nutze den Breadcrumb, wenn die Seite echten Hierarchie-Kontext braucht - nicht als dekorativen Untertitel. Halte ihn dem Hauptseitentitel untergeordnet.

Der Breadcrumb-Vertrag bleibt bewusst klein: semantisches nav, Struktur einer geordneten Liste, per CSS erzeugte Trennzeichen, gedämpfte interaktive Links zu übergeordneten Ebenen und eine zurückhaltende Markierung der aktuellen Seite mit aria-current="page".

Aufbau

KlasseRolleHinweise
wb-breadcrumbPattern-WrapperWende sie auf das semantische nav an.
wb-breadcrumb-listGeordnete ListeNutze ol für die Pfad-Semantik.
wb-breadcrumb-itemHook für ListenelementeVor jedem Element außer dem ersten wird ein Trennzeichen erzeugt.
wb-breadcrumb-linkLink zur übergeordneten EbeneStandardmäßig gedämpft, interaktiv bei Hover/Fokus.
wb-breadcrumb-currentText der aktuellen SeiteKombiniere sie mit aria-current="page".
wb-breadcrumb-compactDichte VarianteNutze sie für Topbars, Drawers und kompaktere Header.

Kanonische HTML-Struktur

<nav class="wb-breadcrumb" aria-label="Breadcrumb">
  <ol class="wb-breadcrumb-list">
    <li class="wb-breadcrumb-item">
      <a class="wb-breadcrumb-link" href="/admin">Dashboard</a>
    </li>
    <li class="wb-breadcrumb-item">
      <a class="wb-breadcrumb-link" href="/admin/pages">Seiten</a>
    </li>
    <li class="wb-breadcrumb-item">
      <a class="wb-breadcrumb-link" href="/admin/pages/home">Home</a>
    </li>
    <li class="wb-breadcrumb-item">
      <span class="wb-breadcrumb-current" aria-current="page">Blocks</span>
    </li>
  </ol>
</nav>

Öffentliche Seiten können dasselbe Pattern nutzen, wenn die Hierarchie die Orientierung verbessert, statt mit der Überschrift zu konkurrieren.

Langer, umbrechender Pfad

  1. Dashboard
  2. Wissensdatenbank
  3. Redaktionsbetrieb und ausführliche Governance-Leitfäden
  4. Einen Review-Ablauf für mehrsprachige Änderungen am Hero-Inhalt der Startseite entwerfen

Umbrüche sind erlaubt. Das Pattern soll ohne JS-Kürzung oder manuelle Trennzeichen lesbar bleiben.

Hinweise zur Barrierefreiheit

LandmarkUmschließe den Breadcrumb mit nav und vergib ein aria-label="Breadcrumb".
Geordneter PfadNutze ol, weil ein Breadcrumb einen geordneten Hierarchiepfad ausdrückt.
Aktuelle SeiteNutze wb-breadcrumb-current und setze aria-current="page". Verlinke die aktuelle Seite nur, wenn es dafür einen fachlichen Grund gibt.
TrennzeichenTippe Trennzeichen nicht von Hand ins Markup. Sie sind rein darstellend und gehören zu CSS.

Tun / Lassen

Tun

Nutze den Breadcrumb für echte hierarchische Navigation.

Halte die Labels knapp.

Kennzeichne die aktuelle Seite barrierefrei.

Nutze die kompakte Variante in dichten Toolbars und Headern.

Lassen

Tippe Trennzeichen nicht von Hand ein.

Nutze den Breadcrumb nicht als dekorativen Untertitel.

Zeige nicht jedes tiefe interne Systemsegment, wenn der Pfad dadurch unruhig wird.

Mache das aktuelle Element nicht standardmäßig zu einem Link.
