# WebBlocks UI v2.41.0 — Card media layouts

Add opt-in image frames and responsive card layouts while preserving existing
card markup, media sizing, alignment and aspect-auto behavior. Existing cards
require no migration.

## Image frames

Use `figure.wb-card-media.wb-card-media--frame` with a direct
`.wb-card-media-viewport`. Keep an optional `figcaption` outside the viewport so
cropping never hides the caption. Images, responsive pictures and image links
use the same anatomy.

Frame modifiers provide contain/cover fitting, natural, 16:9, 16:10, square and
portrait ratios, muted/dark surfaces, thumbnail sizes and focal positioning.

## Placement

Use ordinary DOM order for top, after-header and bottom images. Existing card
regions support inset images and header/footer thumbnails.

Use `wb-card--media-start` or `wb-card--media-end` with a `wb-card-content`
group for horizontal cards. They follow document direction and stack at 640 px.
`wb-card--media-overlay` places the content group inside the viewport after the
image or image link; captions remain outside. Never nest an interactive image
link or viewer trigger inside a whole-card link.

## Upgrade and validation

Pin all UI assets and the downstream AI contract to `v2.41.0`. See
`packages/webblocks/INTEGRATION.md` and the English, German and Turkish
`docs/card-media.html` examples.

Validated source/dist builds, CSS compaction and AI contracts, desktop/mobile
layouts, RTL, dark theme, caption containment and legacy card geometry.
