Native modal and drawer

Opt in with dialog roots while retaining existing WebBlocks APIs and inner markup. Legacy div roots remain supported.

Integration

Native roots use showModal through the existing WebBlocks hooks. Escape, outside clicks and dismiss controls retain the shared close guard.

The dialog needs an accessible name. Do not author open, is-open or tabindex on its root. Native dialog form submission retains validation and returnValue.

<button type="button" data-wb-toggle="modal" data-wb-target="#native-modal">Open native modal</button>
<dialog class="wb-modal" id="native-modal" aria-labelledby="native-title">
  <div class="wb-modal-dialog">
    <div class="wb-modal-header">
      <h2 class="wb-modal-title" id="native-title">Native settings</h2>
      <button type="button" class="wb-modal-close" data-wb-dismiss="modal" aria-label="Close">×</button>
    </div>
    <div class="wb-modal-body">More options</div>
  </div>
</dialog>
