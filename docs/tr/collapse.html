Collapse panel

Mevcut collapse panel sınıflarıyla native açma/kapatma. Buton/div panelleri ve bağımsız collapse desteklenmeye devam eder.

UI her başlıkta açma/kapatma chevron’unu üretir. Yükseltirken elle eklenmiş açma/kapatma ikonlarını kaldırın.

Gelişmiş seçenekler
Gelişmiş ayarlar için sentetik örnek içerik.
Başlangıçta açık
Bu native panel başlangıçta açıktır; yüksekliği JavaScript olmadan içeriğe göre değişir.
Doğrudan gövde
Gövde, wb-collapse sarmalayıcısı olmadan da kullanılabilir.

Entegrasyon

Başlangıç durumu için open kullan. JavaScript yüklüyken mevcut WBCollapse API’si details kökünün id değerini kabul eder.
