Tablo sıralama

Tamamen yüklenmiş yerel veriler ve sunucuda sayfalanan sonuçlar için erişilebilir tek sütun sıralaması.

Standart tablo yapısını koruyun. İstemci modunu yalnızca tüm kayıtlar yüklüyken, sunucu modunu uzak veya sayfalanmış listelerde kullanın. Actions ve seçim sütunları sıralanmaz.

İstemci sıralamasını deneyin

Tab ile başlığa gidip Enter veya Space tuşuna basın. Yeni sütunlar artan sırada başlar; tekrar etkinleştirince azalan sıralanır. Boş değerler iki yönde de sonda kalır.

Başlık göstergeleri, etiketin yanında 16px boyutunda sunulan wb-icon-arrow-up-down, wb-icon-arrow-up ve wb-icon-arrow-down maskelerini kullanır. webblocks-ui.css ile birlikte webblocks-icons.css dosyasını ekleyin; ikon kütüphanesi veya runtime gerekmez.

Bu statik örnek gezinmeyi iptal eder ve istenen URL’yi gösterir. Satırlar ve mevcut sıralama durumu değişmez. Gerçek uygulama, filtrelenmiş veri kümesinin tamamını sayfalamadan önce sıralar ve sonucu gösterir.

URL’yi önizlemek için bir sunucu başlığını etkinleştirin.

Sunucu bağlantıları sonraki sıralama URL’sini içerir ve JavaScript olmadan çalışır. Sunucu butonları mevcut URL’yi veya data-wb-sort-url değerini kullanır. Filtreler ve hash korunur; sayfa 1’e döner. Backend’de sıralama anahtarlarını ve yönlerini izin listesiyle doğrulayın.

<table class="wb-table" data-wb-table-sort="server">
  <caption>Users</caption>
  <thead><tr>
    <th scope="col" data-wb-sort="name" aria-sort="ascending">

    </th>
  </tr></thead>
  <tbody><!-- Rows rendered by the server, sorted by name ascending. --></tbody>
</table>

AJAX entegrasyonu

Veriyi kendiniz almak için wb:table-sort:request olayını iptal edin. Başarılı yanıtı gösterdikten sonra WBTableSort.update ile aria-sort durumunu güncelleyin. Hataları ilgili alanda gösterin ve eski istekleri iptal edin veya yok sayın. Aşağıdaki örnek, uygulamanın endpoint’ini ve DOM oluşturma yardımcılarını gerektirir.

const table = document.querySelector('#users');
const error = document.querySelector('#users-error'); // An inline wb-alert, initially hidden.
const pagination = document.querySelector('#users-pagination'); // Inside wb-card-footer.
let pending;
table.addEventListener('wb:table-sort:request', async (event) => {
  if (event.target !== table || event.detail.mode !== 'server') return;
  event.preventDefault();
  if (pending) pending.abort();
  const request = new AbortController();
  pending = request;
  table.setAttribute('aria-busy', 'true');
  error.hidden = true;
  try {
    const response = await fetch(event.detail.url, {
      signal: request.signal, headers: { 'Accept': 'application/json' }
    });
    if (!response.ok) throw new Error('Request failed');
    const result = await response.json();
    if (pending !== request) return;
    // Host-defined helpers build DOM from validated data using textContent.
    // The endpoint returns rows, pagination, sort and direction after allowlisting.
    const body = renderRows(result.rows);
    const footer = renderPagination(result.pagination);
    table.tBodies[0].replaceWith(body);
    pagination.replaceChildren(footer);
    WBTableSort.update(table, result.sort, result.direction);
    history.replaceState(null, '', event.detail.url);
  } catch (cause) {
    if (pending === request && cause.name !== 'AbortError') error.hidden = false;
  } finally {
    if (pending === request) {
      table.removeAttribute('aria-busy');
      pending = null;
    }
  }
});

WBTableSort.init(fragment) tekrar çağrılabilir. Başlıkları değiştirmeden veya tabloyu kaldırmadan önce destroy kullanın. İstemci modu tek başlık satırını, tek tbody öğesini ve birleştirilmemiş hücreleri destekler. Yerel butonlar klavyeyle etkinleştirilir; sunucu bağlantıları Enter kullanır. Yön, şekil ve aria-sort ile belirtilir; tamamlanan sıralama canlı bölgeden duyurulur.
