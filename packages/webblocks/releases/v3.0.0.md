# WebBlocks UI v3.0.0 — Withdrawn historical record

The v3.0.0 GitHub release and its tag have been removed. This file records the
withdrawal; it is not an installation or upgrade guide. Do not use a v3.0.0 pin.

## Current release: v2.40.0

Use [the v2.40.0 release and migration notes](v2.40.0.md) for current guidance.
v2.40.0 preserves the original v2.39.2 styling for existing div/span detail lists
and supports all three native `dl`/`dt`/`dd` presentations. Existing v2 consumers
do not need an immediate template migration; use semantic description lists or
native tables for new and rewritten interfaces.

Pin all WebBlocks assets and the downstream AI contract to `v2.40.0`:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/fklavyenet/webblocks-ui@v2.40.0/packages/webblocks/dist/webblocks-ui.css">
```

The current pinned AI contract is
[`dist/ai/contract.md`](https://cdn.jsdelivr.net/gh/fklavyenet/webblocks-ui@v2.40.0/packages/webblocks/dist/ai/contract.md).

## Historical context

The withdrawn v3.0.0 release had removed div/span compatibility while adding
three semantic description-list presentations. The supported v2.40.0 release
restores compatibility and retains those native presentations. The earlier v3
installation instructions and download links have been removed from this file
to avoid directing consumers to a removed tag.
