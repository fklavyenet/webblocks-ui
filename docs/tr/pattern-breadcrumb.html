Breadcrumb

wb-breadcrumb, kullanıcının sayfa veya bölüm hiyerarşisi içindeki güncel konumunu gösterir. Yönetim başlıkları, dokümantasyon yüzeyleri, CMS akışları ve daha sakin herkese açık sayfa bağlamı için anlamsal ve JavaScript'siz bir pattern'dir.

PatternJavaScript'sizCSS ayırıcı
Genel Bakış Breadcrumb'ı, sayfa dekoratif bir alt başlık değil gerçek bir hiyerarşi bağlamı gerektirdiğinde kullan. Ana sayfa başlığına göre ikincil kalsın.

Breadcrumb sözleşmesi bilinçli olarak küçük kalır: anlamsal nav, sıralı liste yapısı, CSS ile üretilen ayırıcılar, soluk ve etkileşimli üst düzey bağlantılar ve aria-current="page" ile sessiz bir geçerli sayfa işareti.

Kanonik HTML yapısı

<nav class="wb-breadcrumb" aria-label="Breadcrumb">
  <ol class="wb-breadcrumb-list">
    <li class="wb-breadcrumb-item">
      <a class="wb-breadcrumb-link" href="/admin">Dashboard</a>
    </li>
    <li class="wb-breadcrumb-item">
      <a class="wb-breadcrumb-link" href="/admin/pages">Pages</a>
    </li>
    <li class="wb-breadcrumb-item">
      <a class="wb-breadcrumb-link" href="/admin/pages/home">Home</a>
    </li>
    <li class="wb-breadcrumb-item">
      <span class="wb-breadcrumb-current" aria-current="page">Blocks</span>
    </li>
  </ol>
</nav>
