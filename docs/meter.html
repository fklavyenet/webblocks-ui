Every option uses a 0–100 scale. In a multiple-choice poll, independent percentages can add up to more than 100. Keep the text visible and give each meter an accessible name.

Integration

Use the native min, max and value attributes. UI owns the track and accent fill; the host owns values, localized labels, formatting and visibility. Use a progress indicator for task completion.

<meter class="wb-meter" min="0" max="100" value="60" aria-label="Photography">60%</meter>
