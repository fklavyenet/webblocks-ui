Table sorting

Accessible single-column sorting for complete local data and server-paginated results.

Keep the standard table structure. Use client mode only when every record is loaded; use server mode for remote or paginated lists. Actions and selection columns remain unsortable.

Try client sorting

Tab to a heading and press Enter or Space. New columns start ascending; activate again for descending. Empty values stay last in both directions.

Heading indicators use the shipped wb-icon-arrow-up-down, wb-icon-arrow-up and wb-icon-arrow-down masks at 16px, next to the label. Include webblocks-icons.css alongside webblocks-ui.css; no icon library or runtime is required.

AJAX integration

Cancel wb:table-sort:request to fetch data yourself. Commit aria-sort only after rendering a successful response with WBTableSort.update. Keep errors inline, and abort or ignore stale responses. The following example requires a host endpoint and host-defined DOM rendering helpers.

const table = document.querySelector('#users');
const error = document.querySelector('#users-error'); // An inline wb-alert, initially hidden.
const pagination = document.querySelector('#users-pagination'); // Inside wb-card-footer.
let pending;
table.addEventListener('wb:table-sort:request', async (event) => {
  if (event.target !== table || event.detail.mode !== 'server') return;
  event.preventDefault();
  if (pending) pending.abort();
  const request = new AbortController();
  pending = request;
  table.setAttribute('aria-busy', 'true');
  error.hidden = true;
  try {
    const response = await fetch(event.detail.url, {
      signal: request.signal, headers: { 'Accept': 'application/json' }
    });
    if (!response.ok) throw new Error('Request failed');
    const result = await response.json();
    if (pending !== request) return;
    // Host-defined helpers build DOM from validated data using textContent.
    // The endpoint returns rows, pagination, sort and direction after allowlisting.
    const body = renderRows(result.rows);
    const footer = renderPagination(result.pagination);
    table.tBodies[0].replaceWith(body);
    pagination.replaceChildren(footer);
    WBTableSort.update(table, result.sort, result.direction);
    history.replaceState(null, '', event.detail.url);
  } catch (cause) {
    if (pending === request && cause.name !== 'AbortError') error.hidden = false;
  } finally {
    if (pending === request) {
      table.removeAttribute('aria-busy');
      pending = null;
    }
  }
});

WBTableSort.init(fragment) is safe to repeat. Use destroy before replacing headers or removing a table. Client mode supports one header row, one tbody and no spanning cells. Native buttons provide keyboard activation; server links use Enter. Direction is conveyed through shape and aria-sort, with a polite live announcement after completed sorting.
