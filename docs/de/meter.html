Jede Option verwendet eine Skala von 0–100. Bei Mehrfachauswahl können unabhängige Prozentsätze zusammen mehr als 100 ergeben. Werte bleiben sichtbar; jeder Meter benötigt einen zugänglichen Namen.

Integration

Verwende die nativen Attribute min, max und value. UI gestaltet Schiene und Füllung; die Anwendung verantwortet Werte, übersetzte Beschriftungen, Formatierung und Sichtbarkeit. Für Aufgabenfortschritt verwende eine Fortschrittsanzeige.
