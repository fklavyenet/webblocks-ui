Collapse-Panel

Natives Aufklappen mit den bestehenden Collapse-Klassen. Button/div-Panels und eigenständiges Collapse werden weiterhin unterstützt.

UI zeigt den Chevron zum Auf- und Zuklappen in jeder Überschrift. Entferne beim Upgrade manuell hinzugefügte Aufklapp-Icons.

Erweiterte Optionen
Synthetischer Inhalt für erweiterte Einstellungen.
Anfangs geöffnet
Dieses native Panel ist anfangs geöffnet und passt seine Höhe ohne JavaScript an den Inhalt an.
Direkter Inhalt
Der Inhalt kann auch ohne einen wb-collapse-Wrapper verwendet werden.

Integration

Verwende open für den Anfangszustand. Die bestehende WBCollapse-API akzeptiert bei geladenem JavaScript die id des details-Wurzelelements.
