Integration

Add class="wb-chart" data-wb-chart="line" around a table. Its first column holds category labels; remaining columns are numeric series. Use data-wb-chart-value for unformatted values when cells contain localized text.

For a table elsewhere on the page, set data-wb-chart-table="table-id". The host can put it in a standard modal with a labelled trigger. Call WBChart.update(element) after changing the table and WBChart.destroy(element) before removing the component.
